Developer switch for chrome:// pages

Quit Chrome completely, then start it with --extensions-on-chrome-urls. Pixelpush already asks for chrome:// access in its manifest. Chrome can turn this switch off in some releases, and it never opens other extensions' pages.

macOS

open -a "Google Chrome" --args --extensions-on-chrome-urls

Windows

chrome.exe --extensions-on-chrome-urls
